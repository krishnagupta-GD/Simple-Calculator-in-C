# Simple Calculator in C

A basic console‑based calculator written in C.  
This project demonstrates fundamental C concepts such as input/output, `switch-case`, and basic arithmetic operations. It was created as a first‑semester programming exercise.

## Features

- Supports four operations: addition (`+`), subtraction (`-`), multiplication (`*`), and division (`/`).
- Takes input in the format `number operator number` (e.g., `5.5 * 2`).
- Displays the result formatted to two decimal places.
- Handles invalid operators with an error message.

## How to Run

### Prerequisites

- A C compiler (e.g., GCC).
- A terminal or command prompt.

### Compilation

```bash
gcc calculator.c -o calculator
